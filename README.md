# 🇩🇪 Deutschly AI

AI-powered German learning platform designed especially for Pakistani students.

## Features

- 🇩🇪 German learning path
- 📚 A0 beginner course
- 📝 Interactive quizzes
- 🎯 70% passing system
- ⭐ XP system
- 🤖 AI German translator
- 🇵🇰 Roman Urdu explanations
- 👨‍🏫 AI German tutor
- 🚀 Groq-powered AI
- 📊 Progress tracking

## Tech Stack

- Python
- Streamlit
- Groq API
- SQLite
- GitHub
- Streamlit Community Cloud

## AI Features

Students can enter:

> hi kya haal hai

Deutschly AI converts it into German and provides:

- German translation
- English meaning
- Roman Urdu meaning
- German level
- Explanation
- Word breakdown

## Deployment

This project is designed to run on Streamlit Community Cloud.

Add the following secret:

GROQ_API_KEY

Optional:

GROQ_MODEL

Never expose your API key in the source code.
